# Snowman Meltdown

A simple command-line word guessing game written in Python.

## Features
- Random secret word selection
- Input validation
- Visual snowman melting stages using ASCII art
- Feedback for correct and incorrect guesses
- Replay option

## How to Run

```bash
python snowman.py
```

## Project Structure

- `snowman.py` – Main entry point
- `game/game_logic.py` – Game logic and input handling
- `game/ascii_art.py` – Snowman ASCII art stages
